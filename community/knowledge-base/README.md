# Community knowledge base

Original, practical guides that adapt credited articles into Jev workflows. These guides are independent editorial work: a linked project is not endorsed by the article's author, and a synthetic test is not evidence of model quality.

<!-- knowledge:index:start -->
- [Guard LangChain agent tool calls with Jev and human approval](articles/building-a-jev-agent-harness.md) — Use LangChain's experimental AutoModeMiddleware and Jev to screen risky agent tool calls, keep human approval in code, and log uncertain decisions. Based on [Building a Harness with Jev](https://x.com/sydneyrunkle/article/2100754364545761643) by [Sydney Runkle](https://x.com/sydneyrunkle).
- [Replace LLM decision calls with a Jev gate in Python](articles/jev-decision-gate.md) — Move routing, scoring and approval calls from a frontier LLM to Jev: build a Python ship/return/escalate gate with code-owned thresholds and a shadow-mode rollout. Based on [Jev Engineering: How to Stop Paying a Frontier Model to Make Yes-or-No Decisions (full course)](https://x.com/hanakoxbt/article/2101709924828934222) by [Hanako](https://x.com/hanakoxbt).
- [Jev use cases: nine patterns developers are building](articles/jev-use-cases.md) — What Jev is and what developers build with it: nine community use cases, from browser agents to RAG filtering, with evidence, limits and open projects for each. Based on [WTF Is Jev? 9 Things People Are Already Building With It](https://x.com/mvanhorn/article/2100784142850097482) by [Matt Van Horn](https://x.com/mvanhorn).
- [Jev setup guide: batch questions to cut API costs](articles/jev-api-cost-setup.md) — Set up Jev for the lowest cost per decision: ask every question in one call, trim the state, pin jev-1.13.0, route on confidence and keep math and dates in code. Based on [The Jev Setup Guide: How to Get Maximum Quality for Minimum Cost (Exact Config Inside)](https://x.com/zodchiii/article/2101243146596384854) by [darkzodchi](https://x.com/zodchiii).
- [10 Jev project ideas with practical starting points](articles/jev-project-ideas.md) — Ten Jev project ideas with verified starting points: inbox triage, RAG filtering, model routing, SQL classification and PR review, plus costs and limits. Based on [Top 10 Jev Builds You Can Ship in an Afternoon](https://x.com/0x_rody/article/2103165281149354256) by [rody](https://x.com/0x_rody).
- [Jev decision audits: validate the business case](articles/jev-decision-audit.md) — Build a Jev decision audit with paired outcomes, reviewed thresholds and a complete cost ledger before claiming automation savings or a product opportunity. Based on [Jev Engineering - How to make money with Jev: Best repos](https://x.com/me_barnyx/article/2101976764779999381) by [barnyx](https://x.com/me_barnyx).
