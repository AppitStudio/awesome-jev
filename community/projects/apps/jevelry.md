## When to use

Use when the workflow matches the upstream README. Prefer other catalog apps when you need a different platform or a hosted-only product.

## How it works

Terminal app to make and track everyday decisions with TypeSafe Jev, storing reusable “jevels” locally. Jev supplies typed judgments where configured; application code owns orchestration and side effects.
