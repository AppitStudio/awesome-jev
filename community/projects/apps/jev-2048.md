# Jev 2048

[All projects](../README.md) · [Web apps](README.md#web-apps)

Instrumented 2048 web lab where **every move** is a TypeSafe Jev `Choice` over the four directions with **no heuristic fallback**; probability, confidence, latency, and token cost are shown live. Hosted trial on Vercel plus BYOK backends (TypeSafe, OpenRouter, local System One proxies).

## When to use

Use it when you want a **visible, tunable** demo of how prompt/board context shapes calibrated Jev choices under latency and cost. Prefer [Jev Grand Prix](jev-grand-prix.md) for a continuous-control race demo; prefer [TypeSafe Mario](../tools/typesafe-mario.md) / [Jev Lab](../tools/jev-lab.md) for other simulation labs.

## How it works

Each turn builds board state and asks a single `Choice` over up/down/left/right. [`src/client/api.ts`](https://github.com/ARCJ137442/jev-2048/blob/9582bcf0787dcf7e56bff9bd0f8c9e8a49e5cacc/src/client/api.ts) configures backends (TypeSafe official, OpenRouter `typesafe/jev-1.13`, Vercel trial proxy, local proxies). The UI surfaces the full distribution, confidence, latency, and token cost; prompts and board rules are editable. Code does not substitute a heuristic when Jev returns a choice.

## Get started

```sh

cd jev-2048
```

Live play (hosted or BYOK) sends board state/questions to a System One endpoint and may incur charges. This listing did not start a live game.
