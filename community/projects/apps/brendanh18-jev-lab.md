## When to use

Use when the workflow matches the upstream README. Prefer other catalog apps when you need a different platform or a hosted-only product.

## How it works

Local interactive workbench with small demos showing TypeSafe Jev System One capabilities (playground + Workbench). Jev supplies typed judgments where configured; application code owns orchestration and side effects.
