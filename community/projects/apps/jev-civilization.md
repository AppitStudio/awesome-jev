## When to use

Use when you want this product’s workflow with inspectable Jev judgments. Prefer simpler demos when you only need a minimal Choice example.

## How it works

The app supplies shared state and authored questions; Jev returns typed answers; TypeScript/application code routes, stops, and renders results.
