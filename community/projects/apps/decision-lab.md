## When to use

Use when the workflow matches the upstream README. Prefer other catalog apps when you need a different platform or a hosted-only product.

## How it works

Local visual System One playground for building decisions, comparing Jev, OpenJEV, and Laya, and exploring what-if evidence changes. Jev supplies typed judgments where configured; application code owns orchestration and side effects.
