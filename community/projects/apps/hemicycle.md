# Hémicycle

[All projects](../README.md) · [Web apps](README.md#web-apps)

French civic quiz comparing your answers on real National Assembly votes with each parliamentary group; the nightly pipeline uses an LLM to draft neutral cards and TypeSafe Jev to classify and check them.

## When to use

- Generate neutral, reviewable quiz cards from parliamentary votes.
- Mismatch: French-only content; human review remains required.

## How it works

New scrutins are ingested nightly; an LLM drafts symmetric summaries; Jev assigns category and neutrality checks; deterministic rules strip party and person names. (Summarized from the upstream [README](https://github.com/lduf/hemicycle/blob/07efd4d769c20bd4a74d586c8e38a7835f76bb2a/README.md); not reproduced here.)

## Get started

From the upstream README (not run on the review host): run the pipeline per the README with your keys, then build the static site.

## Limits and data handling

Vote texts and drafts go to TypeSafe. Not run on the review host.
