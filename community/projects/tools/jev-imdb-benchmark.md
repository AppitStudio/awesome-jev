## When to use

Use when benchmark TypeSafe Jev on IMDB reviews (sentiment/spoilers/quality) with published accuracy, latency, and cost. Prefer hosted TypeSafe Jev SDK examples for production TypeSafe API integration when this is independent research.

## How it works

Jev classifies review attributes; harness reports accuracy/latency/cost against labels.
