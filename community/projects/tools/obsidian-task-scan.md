# obsidian-task-scan (find Obsidian tasks a swamp extension could do, using Jev)

[All projects](../README.md) · [Developer tools](README.md#developer-tools)

Swamp extension that lists the open tasks in an Obsidian vault (skipping templates and daily notes), withholds any that look like they contain a secret, and asks Jev whether a swamp extension could do each one, marking tasks candidate (at 0.7 confidence or more), not_candidate, withheld or unclassified; runs on a schedule or on demand.

## When to use

- Find automatable chores hiding in your notes.
- Mismatch: specific to the swamp automation tool; a first draft generated by puddleworks-factory.

## How it works

`extensions/models/obsidian_task_scan.ts` builds a Jev Choice question per task and runs it through the `@swamp/typesafe-ai` model; secret-looking tasks are never sent. Integration evidence: [`extensions/models/obsidian_task_scan.ts`](https://github.com/puddle-works/obsidian-task-scan/blob/384a7761b1b4c7ace896cea2f73c50726c4119aa/extensions/models/obsidian_task_scan.ts).

## Get started

From the upstream README (not run on the review host):

```sh
swamp extension pull @puddleworks/obsidian-task-scan
swamp vault put typesafe TYPESAFE_API_KEY
```

Live commands may contact TypeSafe (or the configured provider) and incur charges. These commands were not run on the review host.
