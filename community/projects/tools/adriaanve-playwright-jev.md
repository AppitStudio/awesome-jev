## How it works

Structured TypeSafe Jev decisions for Playwright: failure triage, smart retries, healer gating, snapshot pruning, locator healing, and test impact ordering. Jev (or a disclosed local/open System One substitute) supplies typed judgments where configured; ordinary application code owns orchestration, I/O, and side effects. See upstream for schemas and failure handling.
