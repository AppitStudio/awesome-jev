## How it works

Metamorphic coherence testing for typed probabilistic decision models: 50 probability/choice laws without gold labels. Jev (or a disclosed local/open System One substitute) supplies typed judgments where configured; ordinary application code owns orchestration, I/O, and side effects. See upstream for schemas and failure handling.
