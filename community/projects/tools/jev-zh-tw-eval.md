## When to use

Use when traditional Chinese (zh-TW) evaluation of Jev-compatible System One models (Plumb-4B via Ollama), including adversarial probes. Prefer related catalog tools when another listing better matches your stack.

## How it works

Local CLI scores Plumb-4B and related System One endpoints on zh-TW tasks, injection probes, and calibration slices; author-reported figures.
