## When to use

Use when salesforce packages for governed Choice/Score/Noul judgments with TypeSafe Jev, org policy, and an immutable ledger (v1 pre-release). Prefer hosted TypeSafe Jev SDK examples for production TypeSafe API integration when this is independent research.

## How it works

TypeSafe Jev supplies typed judgments; Gavel applies org policy and records an immutable ledger (shadow mode first).
