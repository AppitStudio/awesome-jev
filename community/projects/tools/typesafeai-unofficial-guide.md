## When to use

- Learn Jev request patterns with runnable examples.
- Mismatch: community docs, not official TypeSafe documentation; check docs.typesafe.ai for current API.

## How it works

Chapters under `docs/` explain concepts and cookbooks; `examples/` holds Python/TypeScript snippets and a mock server. (Summarized from the upstream [README](https://github.com/typesafe-docs/typesafeai/blob/dffd615f396cc2dde904876bec824990966c15e4/README.md); not reproduced here.)

## Get started

From the upstream README (not run on the review host): read `docs/01-introduction.md` and run an example from `examples/`.

## Limits and data handling

Examples call TypeSafe with your key unless pointed at the mock. Not run on the review host.
