## When to use

Use when rank a GitHub repo's open issues for good-first-issue fit with TypeSafe Jev (size, clarity, project knowledge, claim flags). Prefer related catalog tools when another listing better matches your stack.

## How it works

Fetches issues via GitHub API; Jev scores beginner-friendliness dimensions; code ranks and flags already-claimed work.
