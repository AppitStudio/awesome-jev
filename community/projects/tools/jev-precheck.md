# jev-precheck by Peter Varga (MCP proxy that checks an agent's writes against the records they touch, with code doing the maths and Jev judging)

[All projects](../README.md) · [Developer tools](README.md#developer-tools)

MCP proxy between an agent and any MCP server: reads pass through, and before each write it fetches the records the call touches, derives comparisons in code (duplicates, amount versus typical, conflicting status, missing prerequisite) and asks Jev whether a person should look. Shadow, annotate and enforce modes; held calls are released by hand.

## When to use

- Teams letting agents write into accounting, ERP or other systems of record who want well-formed but wrong calls caught.
- Mismatch: a danger or prompt-injection filter; it judges business mistakes against records, and needs a contract per tool.

## How it works

`src/judge.ts` uses the AI SDK's `experimental_evaluate` with `gateway.evaluationModel("typesafe-ai/jev")` and asks three typed questions in one call: does a person need to see this, what kind of issue it is, and whether the stated reason argues for its own approval. Code derives every number first, following TypeSafe's note that Jev does not compare numbers reliably. Integration evidence: [`src/judge.ts`](https://github.com/alviso/jev-precheck/blob/a58536f035eb1b7e134b017a028f69d8684126fb/src/judge.ts).

## Get started

Copy the env file, install dependencies and run the proxy against the bundled mock ERP contract.

```sh
git clone https://github.com/alviso/jev-precheck && cd jev-precheck
cp .env.example .env   # AI_GATEWAY_API_KEY=...
bun install
bun run src/cli.ts proxy contracts/mock-erp.json
```

Live commands may contact TypeSafe (or the configured provider) and incur charges. These commands were not run on the review host.

## Limits and data handling

Jev calls go through Vercel AI Gateway, not directly to TypeSafe. The 98.6% recall / 0% false-hold figures are the author's, on 288 synthetic wholesaler calls generated by the repo. Fetched records and derived statements go to the judge. Start in shadow mode on real traffic.
