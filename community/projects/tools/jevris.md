## When to use

Use when coding agents need a local decision/verify loop with Jev. Prefer thinner skills for single judgments.

## How it works

Jevris sits beside Claude Code/Codex/OpenCode-style agents as a local decision plane over System One.

## Get started

git clone https://github.com/CryptVenture/Jevris.git

Live Jev/TypeSafe (or other provider) calls send the judged text/state to that provider and may incur charges. Offline/demo paths stay local when documented upstream. Catalog checks did not run live integrations.
