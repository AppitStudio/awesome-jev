## When to use

Use for Chinese-language learning of Choice/Score/Noul, TypeSafe Jev, eval discipline, and the Laya fine-tune path. Prefer official English cookbooks on docs.typesafe.ai when you need OSI-licensed materials or English-only guides.

## How it works

Tutorials teach typed System One questions (Choice/Score/Noul) with offline notebook paths and optional live TypeSafe keys. Application code owns orchestration; Jev supplies calibrated judgments. Online site: [datawhalechina.github.io/jev-cookbook](https://datawhalechina.github.io/jev-cookbook/).
