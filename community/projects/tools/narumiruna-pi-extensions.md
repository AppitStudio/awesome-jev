## How it works

Pi Coding Agent monorepo with experimental TypeSafe packages: pi-typesafe, pi-typesafe-compact, and pi-typesafe-search. Jev (or a disclosed local/open System One substitute) supplies typed judgments where configured; ordinary application code owns orchestration, I/O, and side effects. See upstream for schemas and failure handling.
