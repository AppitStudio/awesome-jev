## When to use

Use for Korean-language hands-on learning of Jev as a decision layer beside an LLM writer. Prefer English cookbooks on docs.typesafe.ai when you need English-only guides.

## How it works

Jev answers typed Choice/Noul-style judgments for tool selection, guardrails, risky-action gates, and RAG folder/file grounding; an LLM writes reply text. Sample app shows per-judgment probability bars.
