# Jev Playground (xingqiux)

[All projects](../README.md) · [Developer tools](README.md#developer-tools)

Local, standard-library Python test bench for Jev: enter text, JSON or images plus Noul, Choice, Score or Box questions, run one request, and see probabilities, raw request/response, cURL and a choice-order sensitivity check, with 60 built-in examples.

## When to use

- Try Jev question designs, including experimental image and Box tasks, before writing code.
- Check how much an answer moves when Choice options are reversed, to size threshold margins.
- Mismatch: distinct from the already-listed frederico-kluser jev-playground (OpenRouter workbench).

## How it works

The page talks only to `server.py` on 127.0.0.1, which adds your key and forwards to `https://api.typesafe.ai/v1/systemone` and `/v1/models`; it can add the image and long-context danger-zone headers and runs a second reversed-order request for the sensitivity test. Integration evidence: [`server.py`](https://github.com/xingqiux/jev-playground/blob/7e2b598eaa969b1fc1d7c98209beb1bdb97a16da/server.py).

## Get started

From the upstream README (not run on the review host):

```sh
git clone https://github.com/xingqiux/jev-playground.git && cd jev-playground
export TYPESAFE_API_KEY=...
python3 server.py   # http://127.0.0.1:5199
```

Live commands may contact TypeSafe (or the configured provider) and incur charges. These commands were not run on the review host.

## Examples and demos

- Built-in scenarios: `scenarios.json` (generated by `tools/gen_scenarios.py`).

## Limits and data handling

Inputs and images go to TypeSafe on your key; drafts are saved to a local `data.json`. Do not expose the port: anyone reaching it can use your key.
