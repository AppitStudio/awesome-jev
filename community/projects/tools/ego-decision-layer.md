## How it works

Pluggable ego lite browser decision layer: one TypeSafe Jev System One call per step with fail-closed execution guards. Jev (or a disclosed local/open System One substitute) supplies typed judgments where configured; ordinary application code owns orchestration, I/O, and side effects. See upstream for schemas and failure handling.
