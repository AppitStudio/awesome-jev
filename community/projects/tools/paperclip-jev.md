## When to use

Use when paperclip fork that routes work tasks automatically with TypeSafe Jev (see TYPesafe issue-router docs). Prefer hosted TypeSafe Jev SDK examples for production TypeSafe API integration when this is independent research.

## How it works

TypeSafe Jev routes issues/tasks; Paperclip application code owns agent orchestration.
