## How it works

Open System I autonomous-driving decision model (DriveJev-4B) scoring behaviours with probabilities in one forward pass; JevPilot closed-loop harness. This is independent research, not an official TypeSafe release. Jev (or a disclosed local/open System One substitute) supplies typed judgments where configured; ordinary application code owns orchestration, I/O, and side effects. See upstream for schemas and failure handling.
