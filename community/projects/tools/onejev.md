## When to use

Use when studying multimodal System One–style decisions locally. Prefer hosted TypeSafe Jev for production text judgments.

## How it works

Answers typed questions over text/image/video with calibrated option probabilities; speaks an extended System One API. Independent of official Jev. Integration evidence: upstream README and source at the pinned commit below.
