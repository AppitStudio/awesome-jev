## When to use

Use when claude Code mod: TypeSafe Jev sets per-task reasoning effort for the main loop, subagents, and Codex delegations (effort-only by default). Prefer related catalog tools when another listing better matches your stack.

## How it works

Jev scores task hardness/risk/effort; hooks rewrite reasoning effort without switching models (cache-friendly); fail-open on errors.
