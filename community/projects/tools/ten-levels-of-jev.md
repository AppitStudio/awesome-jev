## When to use

Use when learning progressive Jev integration patterns for agentic engineering.

## How it works

Levels 1–5 call Jev from code; levels 6–10 put Jev inside the pi coding agent as hooks then tools until the agent writes questions itself. Integration evidence: upstream README and source at the pinned commit below.
