## When to use

Use to compare multilingual local decision models against hosted Jev. Distinct from PromptEngineer48/laya-vs-jev-arena.

## How it works

Runs shared cases through local Laya multilingual MLX, Ollaya arms, and TypeSafe Jev; reports side-by-side. Integration evidence: upstream README at the pinned commit.
