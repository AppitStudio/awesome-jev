## When to use

Use when canvasTTY plugin: System One (Jev/Laya/Eikos) command review, launch triage, and orchestrator advice (requires plugin API v2). Prefer hosted TypeSafe Jev SDK examples for production TypeSafe API integration when this is independent research.

## How it works

Jev/Laya/Eikos (and optional Ollama) review commands and triage tasks; CanvasTTY owns execution gates.
