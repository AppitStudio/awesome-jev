## When to use

Use when cleaning issue backlogs with typed duplicate/topic judgments. Distinct from CMaintz/jev-triage and other similarly named tools.

## How it works

CLI fetches issues via gh/glab, asks TypeSafe Jev typed questions, emits HTML. Integration evidence: upstream README at the pinned commit.
