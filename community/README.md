## Share or improve a project

App makers and tool authors are welcome to submit their work. Follow [the contribution rules](../CONTRIBUTING.md#add-a-community-project) and the [project-page template](PROJECT_TEMPLATE.md). Apps go in `projects/apps/`; tools go in `projects/tools/`. Each submission needs its full page, an entry in the matching directory, and a root README entry.

Pages summarize the linked projects; their maintainers own the upstream code and licenses. Check each page's reviewed version and [validation scope](../docs/validation.md#community-project-checks). A listing does not establish production quality or endorsement.
